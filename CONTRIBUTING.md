# Contributing

Corrections are welcome. Please keep each change focused and include a source or a reproducible explanation when correcting technical material.

- Preserve attribution and avoid adding copyrighted course material without permission.
- Use clear titles, relative links, and fenced code blocks with a language where appropriate.
- Replace live targets and real credentials with lab placeholders; do not add private information.
- Describe tool versions and lab assumptions when behavior depends on them.
- Check links and examples before opening a pull request.
